# PoliticalTurnBasedSim

A turn-based political, economic, diplomatic and military grand-strategy game. The player governs a real-world country from **January 1, 2026** using natural-language commands and conversations.

> The player has unlimited freedom to attempt things, but not unlimited power to make them happen.
> The AI interprets. The simulation decides. The world reacts.
